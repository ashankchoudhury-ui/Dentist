# Unmindy MVP

A mobile-first single-page web app prototype. It runs without a backend, account, API key, or paid service.

## Features
- Pick an activity category or let the app choose
- Interest-based suggestions
- Gentle, firm, and focus modes
- Countdown timer with pause/resume/reset
- Local XP, streak, and completed activity tracking
- Responsive dark interface

## Current limitations
- Preferences and progress are saved in the current browser/device only.
- Account sync is not implemented.
- This is a web app prototype, not an Android APK.
- It cannot detect or close other apps.
